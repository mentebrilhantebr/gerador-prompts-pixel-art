# Gerador de Prompt para Pixel Art e Jogos 2D

Ferramenta web gratuita que monta prompts em inglês, otimizados para IAs de imagem, voltados a **pixel art** e **assets de jogos 2D**: spritesheets, tilesets, ícones e backgrounds parallax.

**Site:** https://geradorprompts-pixel-art.netlify.app/

## O que ela faz

- Estilo visual: 8-bit Retro, 16-bit SNES, Cyberpunk 2D, Fantasia Medieval, Minimalista
- Tipo de asset: Spritesheet de Personagem, Tileset de Cenário, Ícone de Item, Fundo Parallax
- Paleta de cores: neon vibrante, tons pastéis, monocromático, Game Boy clássico
- Detalhes extras: visão lateral, top-down, fundo transparente, pronto para animação
- Prompt montado em tempo real e botão de copiar com feedback

Funciona no celular e no computador, sem instalar nada e sem cadastro.

## Tecnologia

Um único arquivo `index.html` com CSS e JavaScript embutidos. Sem dependências, sem build.

## SEO

- Metatags de título e descrição com palavras-chave de cauda longa
- Dados estruturados JSON-LD (`SoftwareApplication` e `FAQPage`)
- `canonical`, `robots.txt`, `sitemap.xml`, Open Graph e favicon
- Guia com FAQ em cards expansíveis
