Guia: como criar assets 2D e pixel art com IA

Respostas rápidas para desenvolvedores indie e artistas que querem gerar sprites, tilesets e backgrounds com inteligência artificial.

Quais são os melhores parâmetros para gerar pixel art no Midjourney v6?

No Midjourney v6, comece com --v 6 e use --style raw para reduzir o excesso de embelezamento e obter pixels mais limpos.

Ajuste a proporção ao asset: --ar 1:1 para ícones e sprites, --ar 16:9 para backgrounds e --ar 3:2 para tilesets.

Inclua no prompt termos como pixel art, crisp pixels, no anti-aliasing, limited color palette, flat shading. Evite palavras como "realistic" ou "3D render".

Como estruturar prompts para tilesets e spritesheets 2D?

Use uma ordem fixa: estilo → tipo de asset → vista → paleta → fundo → restrições técnicas. É exatamente a ordem que este gerador segue.

Para spritesheets, peça sprite sheet, grid layout, consistent character, idle and walk cycle, side view. Para tilesets, use seamless, modular tiles, top-down view, tileable.

Peça fundo sólido ou transparente para facilitar a remoção e o recorte no editor.

Dicas para manter a consistência de cores em jogos indie

Defina uma paleta fixa de 16 a 32 cores e repita a descrição dela em todos os prompts.

Reutilize a mesma seed e o mesmo estilo-base entre gerações. Depois, padronize as cores em editores como Aseprite ou usando paletas do Lospec antes de importar na engine.

Para um visual retrô autêntico, a paleta Game Boy de 4 tons é uma ótima restrição.
